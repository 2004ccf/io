我与计算机的对比与比较

用人体器官与家庭生活场景类比计算机硬件：CPU、内存、硬盘、主板、网卡、操作系统等对应关系速查。

Jun 30, 2026

写这篇的缘由

学 PLC、进博图之前，我对电脑的理解停在「开机、上网、装软件」。老师讲到 CPU、内存、硬盘时，我脑子里只有规格单上的数字，没有画面。后来我自己试着把电脑部件和人体、和家里怎么运转对照着记——不是严谨类比，而是帮助记忆和建立直觉。这篇是我整理的两套笔记：第一套偏「器官」，第二套偏「家庭生活」。学自动化之后回头看，对照主板、电源、传感器会顺手很多。

第一套：器官对照（浅层）

计算机部件人体对应我记的时候想的
CPU大脑算和调度，决定先干啥
显卡 / 画面帧眼睛把外界「拍」下来再显示
运行内存 RAM短期记忆正在用的，关机就没了
硬盘 / SSD长期记忆照片、软件搁着，断电还在
主板神经系统各部件靠它连在一起
电源心脏供电，没它全停
传感器、键鼠等输入五官接收外界信息

学 PLC 时我第一次分清：内存是程序运行时的「工作台」，断电清空；硬盘是装博图项目、文档的地方，像仓库。以前我把「内存不够」和「磁盘满了」混为一谈，装系统时才真正分开——C 盘满了是硬盘问题，开太多网页卡顿常常是内存问题。

再细一点的八个部件

  1. 网卡 — 像耳朵加嗓子：收数据是听，发数据是说，负责和远处设备交换信息。
  2. 声卡 — 专门管声音进出，输入输出各一路。
  3. 散热器（散热片 / 风扇） — 像出汗、皮肤散热；CPU 高负载时风扇转，不然会烫到降频甚至保护关机。我玩游戏时风扇狂转，就和这套对上了。
  4. USB、HDMI 等接口 — 像手和嘴接外界：U 盘、显示器、外设从这里进出。
  5. 显存 VRAM — 视觉皮层里「正在看的那帧」暂存区，GPU 画图时离不开。
  6. BIOS — 脑干那一挂：开机先初始化硬件，最底层的启动逻辑。
  7. 操作系统（Windows 等） — 前额叶：排任务、分资源、让各硬件别乱套。
  8. 电源适配器 — 消化系统：交流变直流，像把食物转成身体能用的能量。

其中我觉得最贴切的是 CPU–大脑、内存–短期记忆、硬盘–长期记忆、电源–心脏；网卡≈耳朵+嗓子有点勉强，但记「远程交换」够用了。BIOS 和脑干的对应，帮助我理解「为什么开机先过 BIOS 再进系统」。

第二套：家里干什么（我更常用这套复习）

  • CPU：总调度。今天先做饭还是先打扫、快递怎么处理，它排顺序。
  • 内存：厨房操作台。切菜时菜放台上，做完就收走，不能当仓库。
  • 硬盘：储物柜、冰箱。米面、衣服、照片长期放着，出门断电东西还在。
  • 主板：水电管线加走廊，厨房卧室客厅（各硬件）靠它连通。
  • 电源：小区变电加热水器，高压变家用，再给全家电器供能。
  • 散热器：空调风扇。夏天灶台大火（CPU 满载）得降温，不然「罢工」。
  • 键盘 / 鼠标：手，直接操控。
  • 摄像头 / 麦克风：眼和耳，视频会议、语音靠它们。
  • 显示器：脸，把结果展示给我看。
  • 音箱：嘴，把声音放出去。
  • 网卡：手机微信，远程传消息传文件。
  • USB：门锁钥匙孔，外设从这里接进来。
  • 操作系统：管家，不用我逐个家电下指令，它记待办、排资源。

第二套比第一套更「生活化」。我向同学解释「为什么开太多软件会卡」时，会说「操作台摆满了」；解释「为什么要加内存」时，会说「操作台太小」。这种说法不严谨，但对方一听就懂。

和我专业的联系

在 FMTP 产线、博图 里，我联想到：PLC 的 CPU 像总调度；过程映像区里正在运行的数据像内存里的临时量；项目存盘像硬盘。现场 I/O 模块通过总线和 CPU 连，有点像主板上的总线。学通信协议时再回来看「网卡」那条，会更容易接受「数据从哪进、从哪出」。

类比局限（我自己提醒自己的）

类比终归是类比。网卡不等于耳朵，操作系统也不是真的「前额叶」；显卡和眼睛的差异更大——眼睛是传感器，显卡是运算+输出。以后学深了，这些比喻要让位给总线、时钟、中断等概念。但在入门阶段，两套对照让我少背了很多抽象定义。

个人学习笔记，两套类比均来自自己的整理与课堂印象。
