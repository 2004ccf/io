我为什么写这篇

二、核心概念（上课先讲清楚）

2.1 智能组件 = 逻辑 + 模型

智能组件要同时满足两点，缺一则仿真不像真产线：

  1. 逻辑 —— 什么时候动、什么信号触发（后面逻辑块、LB、PLC 对接）
  2. 模型（物体） —— 三维数模、运动范围、包络体

二者要在 PS/VC 里 交互，不是只放一个静态 JT。

2.2 宏程序（Macro Program）

宏程序 = 预定义、可复用的模块化程序块：把一组重复逻辑（动作、判断、参数计算）封装起来，主程序里 调用 + 参数传入。和普通子程序比，强调 参数化，减少重复代码、方便维护。机器人侧和 PLC 侧后面都会用到类似思路。

2.3 「环境」指什么

到 现场 后，一切以 现场实物与 IO 为准；在 课堂/项目 里说的 改环境 指：

部分内容
虚拟环境PS 里模拟的产线：机械结构、动作、传感器信号、物料流
真实关联环境真实 PLC（或 PLCSIM）、通讯与接口，做虚拟—真实联调

PDPS（Process Simulate）是我这阶段 主要操作的「手」 —— 建模型、摆设备、编运动、接信号。

2.4 最小单元与 Resource

设计在上游，仿真/调试在中间，安装在现场下游。Resource 分 简单件 与 组合（集合）；要学会像思维导图一样 从小单元叠到大单元。

操作本质：定义设备 → 落位 → 让机构 按运动过程 动起来 → 做干涉与安全检查。

三、PDPS 标准文件夹与数据体系

3.1 Library 三层对象

以 library → libroot 为根，对象分三类：

类型典型内容
Product工件、零件流
Robot机器人及控制器
Resource设备：布局、转台、输送机、夹具、LB 逻辑块等

项目场景常用 PS2_xxx（如 PS2_1126）标识版本。我本地 PDPS虚拟联调\Library 下能看到 Resource\Device\、Resource\Gripper\、Resource\VC\LB\ 等，和课堂讲的一致。

3.2 标准目录示意

3.3 设备流程：定义 → 落位 → 3D 建模

  1. 定义 —— 明确设备类型（转台、输送机、通用 Device…），生成 TuneData.xml、JT 等
  2. 落位 —— 放置（直接摆位）或 重定位（按坐标/规则调整）
  3. 3D 建模 —— 新建资源 → 柱体/方体 → 参数化 → 安全包络体（防干涉）

干涉 = 集合交集；动态轨迹里 不能碰撞，要先开干涉模式检查。

四、新工程与 Resource 导入（四步）

步骤操作要点
1. 替换 Robot选收集好的数模；.cojt 放到 Resource 对应路径下
2. 定义设备类型建模里 定义组件类型；不移动的物件可标为 Device 通用设备 → 自动生成 TuneData.xml 与 JT
3. 插入组件① 路径在 Resource 目录下 ② 文件为 .cojt ③ 失败常见原因：加密 / 格式不对 / 路径不对
4. 另存为按项目规范命名；我习惯用 Git 管 PS 工程，方便追溯

拿到外部数据时 先看格式，格式一致才能导入。电气侧还要对照 电气原理图；气路侧对照 气路图 / CAD，传感器落位前必须知道检测对象、位置、数量：

5.1 四个高频功能（课堂关键词）

5.2 建模模式

要改变模型 位置与形态，必须进入 建模模式；改完 退出建模，否则容易误改。

路径：打开文件后看窗口 最下方路径栏，确保 Resource 路径正确。

5.3 落位布局

结合 PD 布局做 PS 落位：

  • 创建坐标系：地脚图、找脚边、六值相对地图坐标系
  • 问题记录：定位一个后再定位另一个，之前的可能 偏移 —— 往往要把前一个 固定 或检查约束
  • 包络体：安全包络体覆盖运动范围，仿真时防撞

7.2 推荐顺序（我按老师讲的记）

  1. 先看 布局，定 工艺流程 → 写指南书
  2. PS 里建 复合操作（项目命名如 Loadpart）
  3. 新建对象流 → 导入 3D → 按规则命名
  4. 对象流内：取名 → 选实体 → 拾取坐标选自身，坐标选 实体原点（第 4 项）

  1. 标准模式 下先选好上件/下件模型 → 另存为
  2. 切 生产线仿真模式
  3. 工件 生成外观 → 操作加到 路径编辑器 → 重定位
  4. 放置 到起点，让工件在线体「光幕/传感器」外
  5. 序列编辑器 排序；信号查看器 查 IO

注意：几何中心 vs 车身坐标系要统一；编辑位置时 几何中心 非常关键，重定位要练熟。

7.3 物料流与信号

  • 生产模式下 信号触发 物料流
  • 仿真里可有 PE 函数，如 LP_START_BUTTON，取名 A，标 上升沿
  • 我当时的顺序草稿：序列编辑器 → 信号查看器写逻辑 → 操作树工件进仿真面板 → 播放
  • 虚拟传感器：放置前查气路图/电气图，确认检测对象、位置、数量
  • 接近开关例：LIG_FUB_030_LF1_LC1 —— 信号编辑器会自动带出
  • 信号编辑器必须在生产线仿真模式下 才能正确检查
