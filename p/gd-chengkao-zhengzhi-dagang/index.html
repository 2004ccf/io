广东成人高考专升本《政治》复习大纲

我备考广东成考专升本政治时整理的复习大纲，按哲学、毛概中特、习思想三块梳理考点。

Sep 29, 2026

这是我按《2026年-本科小册子》整理的广东成人高考专升本《政治》复习大纲，方便自己按考点背、按星级抓重点。

资料来源：2026年-本科小册子(1).pdf三个政治部分全文梳理
对照依据：《全国各类成人高等学校招生复习考试大纲（2020年版）》及广东成考专升本近年试卷结构
核验说明：关键表述已对照党的正式文献与权威理论表述纠错（见文末「纠错与补全」）
生成日期：2026-09-29

〇、考情总览（广东成人高考·专升本·政治）

项目内容
试卷满分150 分
考试时间150 分钟
考试方式闭卷笔试
内容比例（大纲）马克思主义哲学约31%；毛泽东思想和中国特色社会主义理论体系概论约62%；时事政治约7%
近年常见题型选择题约 70–80 分；辨析/简答约 50–60 分；论述约 20–40 分（以当年省考试卷为准）

复习策略（与小册子星级对应）

  1. 哲学：重概念辨析、原理+方法论；简答/论述常考「物质与意识」「主观能动性与客观规律」「实践与认识」「人民群众」。
  2. 毛概+中特：背准「总路线、纲领、法宝、本质、三个代表、科学发展观」等固定表述。
  3. 习思想：近年权重上升；背准「新时代主要矛盾、中国式现代化五特色、两步走、两个确立、新发展理念、全过程人民民主」等。
  4. 时事：考前一年国内外重大时政（约占 7%），大纲不在本册三部分内，需另补当年时政。

星级说明：★★★ 高频必背｜★★ 常考｜★ 了解

第一部分 马克思主义哲学原理

第一章 马克思主义哲学是科学的世界观和方法论

考点1 哲学是理论化、系统化的世界观 ★★

  • 哲学：世界观的理论形态；既是世界观也是方法论。
  • 哲学与具体科学：一般与个别的关系。
  • 哲学具有时代性、民族性、阶级性。
  • 易错：说「马克思主义哲学是世界观和方法论」不完整 → 应强调是科学的世界观和方法论。

考点2 哲学的基本问题【重点】★★★

  • 基本问题：思维与存在（物质与意识）的关系问题。
  • 两个方面：

  1. 何者第一性 → 划分唯物 / 唯心；

  2. 思维能否正确认识存在 → 划分可知论 / 不可知论。

  • 不属于基本问题：物质与运动、物质与时间等。

考点3 哲学的两个基本派别 ★★★

  • 唯物主义：物质第一性、意识第二性。
  • 唯心主义：意识第一性、物质第二性。
  • 唯物主义三种历史形态：古代朴素唯物主义 → 近代形而上学唯物主义 → 辩证唯物主义和历史唯物主义。
  • 唯心主义两种形态：主观唯心主义（心、感觉等）／客观唯心主义（理、上帝、绝对精神等）。
  • 近代形而上学唯物主义三大缺陷：机械性、形而上学性、不彻底性（唯心史观）。

考点4 辩证法与形而上学 ★★

  • 辩证法：联系、运动、发展的观点。
  • 形而上学：孤立、静止、片面的观点。
  • 马克思主义哲学直接理论来源：德国古典哲学。
  • 基本特征：实践性、科学性、革命性；实践性是最显著、最根本特征。

第二章 世界多样性和物质统一性

考点1 物质观【重点】★★★

  • 列宁物质定义：物质是标志客观实在的哲学范畴……不依赖于感觉而存在，可为感觉所反映。
  • 物质的唯一特性：客观实在性。
  • 物质的根本属性 / 存在方式：运动。
  • 理论意义：坚持唯物一元论与可知论；克服旧唯物论缺陷；统一自然观与历史观。

考点2–3 运动与静止 ★★★

  • 物质与运动不可分割：没有不运动的物质，也没有脱离物质的运动。
  • 运动绝对、静止相对。
  • 静止两种情形：相对位置不变；根本性质暂时未变。
  • 反对：绝对运动论（相对主义诡辩论）／绝对静止论（形而上学）。
  • 认识相对静止是理解物质多样性的前提。

考点4 规律 ★★★

  • 规律：事物运动发展中本质的、必然的、稳定的联系；根本特点是客观性。
  • 人不能创造、消灭、改变规律，但可以认识、利用规律。

考点5 意识的本质 ★★★

  • 生理基础：意识是人脑的机能。
  • 内容：意识是客观存在的主观映像（客观内容 + 主观形式）。
  • 起源：自然界长期发展产物 + 社会劳动产物。

考点6 物质和意识的辩证关系【重点】★★★

  1. 物质决定意识（物质第一性，意识第二性）。
  2. 意识对物质有能动反作用：正确意识促进发展，错误意识阻碍发展。

考点7 主观能动性与客观规律性【重点】★★★

  • 尊重客观规律是发挥主观能动性的前提。
  • 认识和利用规律必须发挥主观能动性。
  • 正确发挥意识能动作用的客观前提：对客观规律的正确反映。

考点8 一切从实际出发、实事求是 ★★

  • 从客观实际出发，找出规律，按规律办事；与时俱进、解放思想。
  • 哲学依据：世界物质统一性原理。
  • 辨析纠错：「世界统一于存在」→错误。正确：世界统一于物质（「存在」可含精神）。

第三章 事物的联系、发展及其规律

考点1 唯物辩证法总特征 ★★★

  • 总特征：普遍联系 + 永恒发展。
  • 联系：普遍性、客观性、多样性、条件性。
  • 发展实质：新事物产生、旧事物灭亡。
  • 对比：对立统一规律是唯物辩证法的实质与核心（不是总特征）。

考点2 三大基本规律 ★★★

对立统一规律、质量互变规律、否定之否定规律。

考点3–4 矛盾及其基本属性【重点】★★★

  • 矛盾 = 对立统一。
  • 基本属性：同一性（相互依存、相互贯通，有条件、相对）+斗争性（相互排斥、相互分离，无条件、绝对）。
  • 同一性和斗争性相结合构成矛盾运动，推动事物发展。
  • （表述规范：矛盾着的对立面，非「矛盾者」。）

考点5 内因与外因 ★★★

  • 内因：根据，第一位；外因：条件；外因通过内因起作用。

考点6 两点论与重点论 ★★★

  • 矛盾问题精髓：普遍性与特殊性辩证关系；具体问题具体分析是马克思主义活的灵魂。
  • 主要矛盾 / 次要矛盾；矛盾主要方面 / 次要方面。
  • 方法论：以经济建设为中心（重点论）+「两手抓」（两点论）。

考点7 量变质变方法论 ★★★

  • 量变：数量、场所变更；质变：性质根本变化。
  • 量变是质变必要准备；质变是量变必然结果；相互渗透。
  • 方法论：重视量的积累；把握适度；不失时机促成质变。

考点8 辩证否定观 ★★★

  • 实质：扬弃（既克服又保留）。
  • 反对肯定一切或否定一切；否定之否定揭示前进性与曲折性统一。

考点9–11 基本范畴方法论 ★★

范畴方法论要点
现象与本质透过现象看本质；假象也是客观的
内容与形式内容决定形式；反对形式主义
必然与偶然立足必然性；利用有利偶然因素

第四章 实践和认识及其发展规律

考点1 实践 ★★★

  • 含义：人类能动地改造和探索现实世界的社会性物质活动。
  • 特征：客观物质性、自觉能动性、社会历史性。
  • 基本形式：生产实践、处理社会关系的实践、科学实验。

考点2 实践对认识的决定作用 ★★★

  1. 来源 2. 动力 3. 检验真理唯一标准 4. 目的（最终目的）

考点3 认识的辩证发展过程 ★★★

  • 第一次飞跃：感性认识 → 理性认识。
  • 第二次飞跃：理性认识 → 实践（意义更重大）。
  • 总过程：实践—认识—再实践—再认识，循环往复、无限发展。
  • 感性：感觉、知觉、表象；理性：概念、判断、推理。

考点4 真理与实践检验 ★★★

  • 真理根本属性：客观性；绝对性与相对性统一。
  • 实践检验标准具有确定性与不确定性。
  • 论述要点：真理本性（主观符合客观）+ 实践直接现实性。

第五章 历史观的基本问题和社会发展的基本规律

考点1–2 历史观基本问题 ★★★

  • 社会存在与社会意识的关系问题。
  • 唯物史观：社会存在决定社会意识；社会意识相对独立并可反作用。
  • 唯心史观两大缺陷：夸大精神力量；否认人民群众历史创造作用。

考点3 生产方式 ★★★

  • 地理环境、人口是重要条件，不起决定作用。
  • 生产方式在社会发展中起最终决定作用（生产力与生产关系的统一）。

考点4–5 上层建筑与国家 ★★

  • 思想上层建筑（意识形态）+ 政治上层建筑（政权、制度、军队、法院等）。
  • 国家政权是政治结构核心；国家本质是阶级统治工具，阶级性是根本属性。

第六章 社会历史发展的动力

考点1–2 社会基本矛盾 ★★★

  • 生产力决定生产关系，生产关系反作用于生产力。
  • 经济基础决定上层建筑，上层建筑反作用于经济基础。
  • 两对矛盾 = 社会基本矛盾 = 社会发展根本动力。
  • 生产力实体要素：劳动者、劳动资料、劳动对象；劳动者最活跃。

考点3 改革与革命 ★★★

对比改革革命
性质量变质变
范围可广泛于各领域主要集中于政治领域
主体统治阶级被统治阶级
目的维护完善现行制度推翻现行制度
  • 社会主义改革：制度自我完善与发展。
  • 阶级斗争是阶级社会发展的直接动力。

考点4 科学技术是第一生产力 ★★★

  • 科技是现代生产力必要要素和推动发展的首要要素；注意双重社会效应。

考点5–6 人民群众与群众路线 ★★★

  • 人民群众：创造物质财富、精神财富；社会变革决定力量。
  • 群众路线：一切为了群众、一切依靠群众；从群众中来、到群众中去。
  • 评价历史人物：历史分析法 + 阶级分析法。

第二部分 毛泽东思想和中国特色社会主义理论体系概论

第一章 马克思主义中国化时代化的历史进程与理论成果 ★★★

要点标准表述
「两个结合」马克思主义基本原理同中国具体实际相结合、同中华优秀传统文化相结合
第一次历史性飞跃毛泽东思想
新的飞跃（中国特色社会主义理论体系）邓小平理论、「三个代表」重要思想、科学发展观等
新的飞跃（新时代）习近平新时代中国特色社会主义思想（当代中国马克思主义、二十一世纪马克思主义）
首次正式提出「马克思主义中国化」六届六中全会，毛泽东《论新阶段》
重要论断中国共产党为什么能，中国特色社会主义为什么好，归根到底是马克思主义行，是中国化时代化的马克思主义行

注意：毛泽东思想不属于中国特色社会主义理论体系。

第二章 毛泽东思想及其历史地位 ★★★

  • 活的灵魂：实事求是、群众路线、独立自主（精髓是实事求是）。
  • 确立为指导思想：中共七大。
  • 主要内容六方面：新民主主义革命理论；社会主义革命和建设理论；人民军队和军事战略；政策和策略；思想政治工作和文化工作；党的建设。
  • 历史地位：革命胜利思想武器；立国建国思想政治基础；邓小平理论思想渊源和理论先导；民族团结振兴精神支柱。

第三章 新民主主义革命理论 ★★★（高频）

考点要点
基本国情半殖民地半封建社会（外无民族独立，内无人民民主）
主要矛盾①帝国主义与中华民族（最主要）②封建主义与人民大众
革命任务反帝反封建
新旧民主革命共同点同属资产阶级民主主义革命（性质相同）
区别领导权、指导思想、革命前途不同
总路线（1948《在晋绥干部会议上的讲话》）无产阶级领导的，人民大众的，反对帝、封、官的革命
对象帝、封、官（三座大山）
动力无产、农民、城市小资产、民族资产阶级
领导无产阶级；农民是主力军；工农联盟是最主要同盟军
性质 / 前途资产阶级民主主义革命 / 社会主义
政治纲领无产阶级领导、工农联盟为基础的人民民主专政的新民主主义共和国
经济纲领两没收一保护：没收地主土地归农民；没收官僚资本归国家；保护民族工商业
文化纲领民族的、科学的、大众的文化
道路农村包围城市、武装夺取政权
三大法宝统一战线、武装斗争、党的建设
三湾改编核心支部建在连上

第四章 社会主义改造理论 ★★★

  • 新民主主义社会性质：过渡性社会。
  • 五种经济成分：国营、合作社、个体、私人资本主义、国家资本主义。
  • 新中国成立后进入新民主主义社会（非立即社会主义社会）。
  • 过渡时期总路线：一化三改；工业化是主体，三大改造是两翼；建设与改造同时并举。
  • 农业改造步骤：互助组（萌芽）→ 初级社（半社会主义）→ 高级社（完全社会主义）。
  • 手工业：供销小组 → 供销合作社 → 生产合作社。
  • 资本主义工商业：和平赎买；国家资本主义是主要形式。
  • 1956 年底三大改造基本完成 → 社会主义基本制度确立 → 进入社会主义初级阶段。
  • 1954 年 9 月一届全国人大通过《中华人民共和国宪法》。

第五章 社会主义建设道路初步探索 ★★★

  • 《论十大关系》（1956.4）：探索中国社会主义建设道路；基本方针——调动一切积极因素为社会主义事业服务；首先阐述重工业与轻工业、农业关系。
  • 《关于正确处理人民内部矛盾的问题》（1957）：两类矛盾；人民内部矛盾用民主、说服教育方法解决。
  • 社会主义社会基本矛盾仍是生产力与生产关系、经济基础与上层建筑的矛盾。
  • 初步探索意义：开始摆脱苏联模式；为邓小平理论提供思想材料；正确原则与经验总结。

第六章 中国特色社会主义理论体系的形成发展 ★★★

  • 组成：邓小平理论 +「三个代表」重要思想 + 科学发展观 + 习近平新时代中国特色社会主义思想（不含毛泽东思想）。
  • 历史起点：十一届三中全会。
  • 精髓：解放思想、实事求是、与时俱进、求真务实。
  • 各自定位：邓小平——开创；三个代表——推向 21 世纪；科学发展观——新起点上坚持发展。

第七章 邓小平理论 ★★★

  • 回答的基本问题：什么是社会主义、怎样建设社会主义。
  • 社会主义本质：解放生产力，发展生产力，消灭剥削，消除两极分化，最终达到共同富裕。
  • 最大实际：社会主义初级阶段。
  • 基本路线：一个中心、两个基本点。
  • 「三个有利于」判断标准。
  • 历史地位：马列主义与中国实际相结合的第二次历史性飞跃的理论成果；十五大确立为党的指导思想；中国特色社会主义理论体系开篇之作。

第八章 「三个代表」重要思想 ★★★

  • 集中概括：始终代表中国先进生产力的发展要求、先进文化的前进方向、最广大人民的根本利益。
  • 回答：建设什么样的党、怎样建设党。
  • 十六大确立为指导思想；立党之本、执政之基、力量之源。

第九章 科学发展观 ★★★

  • 回答：实现什么样的发展、怎样发展。
  • 第一要义：发展；核心：以人为本；基本要求：全面协调可持续；根本方法：统筹兼顾。
  • 十八大确立为党的指导思想。

第三部分 习近平新时代中国特色社会主义思想概论

第一章 创立 ★★★

三大时代课题

  1. 新时代坚持和发展什么样的中国特色社会主义、怎样坚持和发展；
  2. 建设什么样的社会主义现代化强国、怎样建设；
  3. 建设什么样的长期执政的马克思主义政党、怎样建设。

定位：当代中国马克思主义、二十一世纪马克思主义；中华文化和中国精神的时代精华；实现马克思主义中国化时代化新的飞跃。

主要内容结构

  • 「十个明确」
  • 「十四个坚持」（基本方略）
  • 「十三个方面成就」
  • 「六个必须坚持」（世界观和方法论，小册子未单列，考试常考，已补全）：人民至上、自信自立、守正创新、问题导向、系统观念、胸怀天下。

第二章 新时代坚持和发展中国特色社会主义 ★★★

  • 中国特色社会主义是改革开放以来党的全部理论和实践的主题。
  • 新时代社会主要矛盾：人民日益增长的美好生活需要和不平衡不充分的发展之间的矛盾。
  • 两个没有变：社会主义初级阶段基本国情没有变；世界最大发展中国家的国际地位没有变。

第三章 中国式现代化 ★★★（近年最热）

定义：中国共产党领导的社会主义现代化。

五个中国特色

  1. 人口规模巨大的现代化
  2. 全体人民共同富裕的现代化
  3. 物质文明和精神文明相协调的现代化
  4. 人与自然和谐共生的现代化
  5. 走和平发展道路的现代化

本质要求（九条）：坚持党的领导；坚持中国特色社会主义；高质量发展；全过程人民民主；丰富人民精神世界；全体人民共同富裕；人与自然和谐共生；构建人类命运共同体；创造人类文明新形态。

两步走

  • 2020–2035：基本实现社会主义现代化；
  • 2035–本世纪中叶：建成富强民主文明和谐美丽的社会主义现代化强国。

重大原则：坚持和加强党的全面领导；坚持中国特色社会主义道路；坚持以人民为中心的发展思想；坚持深化改革开放；坚持发扬斗争精神。

第四章 坚持党的全面领导 ★★★

  • 党的领导是中国特色社会主义最本质的特征、制度最大优势。
  • 两个确立：确立习近平同志党中央的核心、全党的核心地位；确立习近平新时代中国特色社会主义思想的指导地位。
  • 两个维护：坚决维护习近平总书记党中央的核心、全党的核心地位；坚决维护党中央权威和集中统一领导。
  • 党的领导是全面的、系统的、整体的；党的领导制度是我国根本领导制度。

第五章 坚持以人民为中心 ★★★

  • 江山就是人民，人民就是江山；人民对美好生活的向往就是奋斗目标。
  • 发展为了人民、依靠人民、成果由人民共享。
  • 人民是历史创造者，是决定党和国家前途命运的根本力量。
  • 共同富裕是社会主义的本质要求。

第六章 全面深化改革开放 ★★★

  • 改革开放是决定当代中国命运、决定民族复兴的关键一招。
  • 总目标：完善和发展中国特色社会主义制度，推进国家治理体系和治理能力现代化。
  • 坚持社会主义方向；问题导向；正确处理改革发展稳定关系；推进高水平对外开放、制度型开放。

第七章 推动高质量发展 ★★★

  • 高质量发展是全面建设社会主义现代化国家的首要任务。
  • 新发展理念：创新、协调、绿色、开放、共享。
  • 新发展格局：以国内大循环为主体、国内国际双循环相互促进。
  • 现代化经济体系；新质生产力；乡村振兴；区域协调发展。

第八章 教育、科技、人才 ★★★

  • 教育、科技、人才是基础性、战略性支撑。
  • 科技是第一生产力、人才是第一资源、创新是第一动力。
  • 教育优先；高水平科技自立自强；人才强国。

第九章 全过程人民民主 ★★★

  • 社会主义民主政治的本质属性；最广泛、最真实、最管用。
  • 五大环节：民主选举、协商、决策、管理、监督。
  • 根本政治制度：人民代表大会制度。
  • 基本政治制度：中共领导的多党合作和政治协商制度、民族区域自治制度、基层群众自治制度。
  • 社会主义协商民主是实践全过程人民民主的重要形式。

第十章 全面依法治国 ★★★

  • 总目标：建设中国特色社会主义法治体系，建设社会主义法治国家。
  • 「共同推进」：依法治国、依法执政、依法行政。
  • 「一体建设」：法治国家、法治政府、法治社会。
  • 党的领导、人民当家作主、依法治国有机统一；习近平法治思想是根本遵循。

第十一章 建设社会主义文化强国 ★★

  • 牢牢掌握意识形态工作领导权。

  • 社会主义核心价值观：

  • 国家：富强、民主、文明、和谐

  • 社会：自由、平等、公正、法治

  • 公民：爱国、敬业、诚信、友善

  • 民族精神核心：爱国主义；时代精神核心：改革创新。

  • 坚定文化自信。

第十二章 保障和改善民生 ★★★

  • 民生是幸福之基、和谐之本；在发展中保障和改善民生。
  • 就业是最大的民生。
  • 社会保障、健康中国、完善分配；共建共治共享社会治理。

第十三章 社会主义生态文明 ★★★

  • 绿水青山就是金山银山；尊重、顺应、保护自然。
  • 绿色发展；碳达峰碳中和；健全生态制度体系。

第十四章 维护和塑造国家安全 ★★★

总体国家安全观

  • 宗旨：人民安全
  • 根本：政治安全
  • 基础：经济安全
  • 坚持国家利益至上；统筹发展和安全。

第十五章 国防和军队 ★★

  • 党对军队绝对领导是建军之本、强军之魂。
  • 强军目标：听党指挥、能打胜仗、作风优良；建设世界一流军队。
  • 政治建军、改革强军、科技强军、人才强军、依法治军；富国和强军相统一。

第十六章 一国两制和祖国统一 ★★★

  • 「一国两制」是港澳长期繁荣稳定的最佳制度；爱国者治港、治澳。
  • 一个中国原则是两岸关系政治基础；九二共识核心是一个中国原则。
  • 解决台湾问题、实现完全统一是民族根本利益；坚决反对「台独」。

第十七章 大国外交与人类命运共同体 ★★★

  • 独立自主的和平外交政策；和平共处五项原则是基本准则。
  • 人类命运共同体核心内涵：持久和平、普遍安全、共同繁荣、开放包容、清洁美丽的世界。
  • 「一带一路」：共商共建共享；推动新型国际关系。

第十八章 全面从严治党 ★★★

  • 全面从严治党是新时代党的自我革命伟大实践；勇于自我革命是显著标志。
  • 政治建设是党的根本性建设（摆在首位）。
  • 思想建设是基础性建设；理想信念是精神之钙。
  • 不敢腐、不能腐、不想腐一体推进；健全全面从严治党体系。

高频主观题速记模板

简答必背（哲学）

  1. 物质与意识：物质决定意识；意识能动反作用。
  2. 内因外因：内因根据；外因条件；外因通过内因。
  3. 实践是认识基础：来源、动力、检验标准、目的。
  4. 认识过程：感性→理性→实践，循环往复。
  5. 群众创造历史：物质财富、精神财富、社会变革。

简答必背（毛概/中特）

  1. 毛泽东思想活的灵魂；近代两大主要矛盾；三大法宝；三大经济纲领。
  2. 过渡时期总路线；社会主义本质；三个代表概括；科学发展观核心。

简答/论述必背（习思想）

  1. 新时代主要矛盾；中国式现代化五个特色；全面深化改革总目标。
  2. 全过程人民民主；人类命运共同体内涵；总体国家安全观（宗旨/根本/基础）。
  3. 论述「以人民为中心」：联唯物史观人民群众原理。

辨析常见陷阱

  • 「世界统一于存在」→ 错，统一于物质。
  • 「马克思主义哲学是世界观和方法论」→ 不完整，应加「科学的」。
  • 「人口因素起决定作用」→ 错，生产方式起决定作用。
  • 「改革集中在政治领域」→ 错，改革可广及各领域，革命才主要集中政治领域。

纠错与补全（对照小册子 + 互联网核验）

序号小册子原文/缺陷纠正 / 补全依据要点
1「矛盾者的对立面」应为「矛盾着的对立面」通用教材规范表述
2主要内容写「十个明确、十四个坚持、十三个方面成就」补全「六个必须坚持」（人民至上、自信自立、守正创新、问题导向、系统观念、胸怀天下）党的二十大报告；求是等权威阐释
3「两个飞跃」表述易混毛泽东思想=第一次历史性飞跃；中国特色社会主义理论体系=新的飞跃；习思想=马克思主义中国化时代化新的飞跃《历史决议》及权威表述
4时事政治未收录另补考前一年国内外重大时政（约 7%）成考大纲试卷内容比例
5例题苛刻表述「科学的世界观和方法论」才是完整标准答案小册子自带解析，备考时按完整表述作答
