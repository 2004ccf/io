虚拟调试技术介绍

蓝经理培训班笔记：PD 工艺规划、PS 仿真、VC 虚拟调试与 PLC/HMI 联调流程。

May 22, 2026

这篇笔记从哪来

蓝经理培训班里，虚拟调试是连着 PDPS（Process Designer + Plant Simulation） 和 博图 PLC 一起讲的。我根据课堂导图 pdps虚拟仿真.gmind 和微信文章 为什么一定要学仿真 整理了这篇，方便以后做项目时对照：先搞清 PD、PS、VC 各干什么，再记数据准备和联调步骤。

整体链条可以记成：PD（工艺规划）→ PS（仿真与数据）→ VC（虚拟调试与 PLC 对接）。

什么是虚拟调试

虚拟调试是在 虚拟环境 里和 PLC 对接，完成整条产线电气与功能的验证。在虚拟调试软件中搭好工作场景，对 设计方案、机器人程序、PLC 程序、HMI 程序 做联调测试，提前从工艺、逻辑、节拍、安全等方面做全面检查——真上现场之前，很多问题能在电脑里暴露出来。

我学下来的好处：少占真机时间、改程序成本低、干涉和节拍可以先在仿真里试，和后面「博图按钮联动 PDPS」的项目实战是连着的。

课堂原话我记了一句：虚拟调试的价值是降低现场事故率、缩短周期、保证质量——PLC/机器人程序在进现场前先在虚拟环境里和电气 IO 对一遍，碰撞、点位配不上、联锁遗漏都尽量在这一阶段暴露。

项目链四阶段（课堂讲的）

整线项目我记成四个大阶段，输入输出物要对上，否则 VC 阶段会返工：

  1. 前期技术 — 方案、报价、节拍与工艺意图（和客户对齐）
  2. 设计制造 — 机械仿真出布局/数模 → 电气分配 IO → 虚拟调试并行于部分现场电装
  3. 现场调试 — 安装完成后，用 VC 阶段确认过的 PLC/机器人程序上真机
  4. 验收交付 — 生产陪伴、项目收尾

虚拟调试接的是 机械仿真 + 电气设计 的输出，向现场输出 已联调程序 + KPI/节拍数据。

PD：工艺规划（Process Designer）

PD 是工艺规划软件，完成生产工艺过程的规划、分析、确认和优化，是后续用 PS 做仿真验证的 前提。通常通过服务器与 Oracle 数据库相连（企业项目里由平台统一管理工艺数据）。

主要用途（我记的要点）：

  • 客户数据导入
  • 建立项目、建立库 Library
  • 创建零件 / 设备 / 制造特征数据
  • 工艺规划、3D 布局
  • 完成项目的工艺规划与工艺信息管理

没有 PD 侧工艺和数据打底，后面 PS 里的布局和节拍容易和真实产线对不上。

PS：数据准备环节

PS 基础操作（课堂列的）

  • 项目创建与资源导入
  • 设备布局与安装
  • 简易 3D 建模
  • 运动机构制作

三类数据要齐

1. 机械数据

收集并检查：前期工艺方案与生产节拍表；机械设计阶段的气路图、PSZX 格式仿真数据、Layout 布局图等。

2. 电气控制数据

电气设计环节提供的：电气控制信号、联锁号表等。

3. 机器人数据

根据电气环节输入的机器人标准、信号、干涉区图等，制作机器人信号表、宏程序、机器人主程序等。

数据不齐就联调，后面 VC 阶段会反复返工——这是我上课记的重点。

VC：设计环节

ROB HOLP（机器人离线编程）

主要工作：虚拟仿真环境里配置机器人控制器；制作与优化机器人路径；OLP 逻辑编程；程序评审与优化。

VC 仿真环境设计

  • 创建上下件操作
  • 物料流创建
  • 虚拟传感器创建
  • 逻辑块与智能组件创建
  • 传感器信号匹配、SC 信号匹配

VC 机器人设计

  • 机器人控制器设置及坐标设置
  • 机器人信号创建与导入
  • 机器人轨迹制作、轨迹信号编程
  • 创建机器人程序及程序启动逻辑块

VC 虚拟调试：手动、自动与功能验证

  • 手动调试：单步看信号、动作是否符合预期。
  • 自动联调：PLC、HMI、机器人程序一起跑流程。
  • 功能验证：HMI 功能、报警检查、设备功能验证等；包括 HMI 详细功能检查，以及故意触发安全条件、检验程序稳定性和安全性（课堂称为对程序做「恶意」或边界条件核验）。

这一阶段和博图里写的 PLC 逻辑、HMI 画面是对上的——我在「所有项目的总结集合」里记的博图按键 → PDPS 信号查看器 → LB 逻辑块，就是联调落地的一种做法。

虚拟调试五大工作环节（课堂标准）

环节我理解的交付物
1. 数据准备机械 PS 数模、电气 IO 表、机器人信号表
2. VC 设计上下件、物料流、虚拟传感器、逻辑块、SC 匹配
3. 虚拟调试PLC + HMI + 机器人程序联调、撞机/IO 问题在此暴露
4. 审核与交付确认版程序、KPI/节拍数据交给现场
5. 现场调试支持真机安装后的微调（可与装配并行，但真机仍常需要）

项目四阶段（前期技术 → 设计制造 → 现场调试 → 验收）和上面五环节是嵌套关系——我写在 FMTP 博图大部头 和本笔记里，面试时被问到「虚拟调试在产线哪一环」就按这张表答。
