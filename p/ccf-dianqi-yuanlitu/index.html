配线培训第二讲：我为什么先记原理图

配线之前得看懂原理图——不看图就接线，线号对不上端子是常事。这是智能控制柜配线培训 第二讲 的课堂笔记，我保留了当时的疑问和截图；第三讲 按流程表配线 是在能看图之后再动手，和 FNTP 两天入门 里的原理图链接也能对照。

我看图时的两个抓手

看懂电气原理图，本质上就 两点：

类型是什么怎么认
线缆带 线号 的黑色连线图纸上的线 + 编号（如 105、106、130）
器件不是线 的一切图形符号空开、接触器、继电器、按钮、模块等

读图逻辑链：

  1. 搞明白 器件是什么（查图例说明）。
  2. 搞明白 器件装在底板什么位置（查底板布局图）。
  3. 根据 线号，把线缆接到器件 对应接线端子 上。 在上图前提下 有了下来的3个文件

三个必备文件（缺一不可）

文件作用
① 电气原理图十几页主图：器件逻辑关系 + 线号 + 回路
② 电气原理图图例说明每个符号代表什么器件（空开、接触器、继电器…）
③ 底板器件布局图每个器件在柜内底板的 物理安装位置

第一讲还涉及 面板布局图（按钮、旋钮装在面板上）—— 读按钮类器件时需要 第四份文件。

三文件配合流程：

1

图例说明 → 认符号 → 原理图定位器件 → 布局图找物理位置 → 按线号配线到端子

读图标准两步（配线前必做）

步骤 1：认器件

  • 打开 图例说明，对照原理图 逐页 识别所有器件。
  • 知道每个符号 是什么（名称、型号参数）。

步骤 2：定位置

  • 打开 底板布局图（按钮类还要 面板布局图）。
  • 知道每个器件 装在什么位置。
  • 之后才能按线号把线接到 正确端子。

本节结论： 先完成「是什么 + 放哪里」，才有可能按配线流程表和原理图配线。

图例说明 · 符号与器件识别

空开（断路器）

符号识别： 图例中矩形 + 上下多对接线端子。

「几 P」含义： P = 上下有几对接线端子（极数）。

标注含义
1P从上到下 1 对 端子
2P2 对 端子
3P3 对 端子
4P4 对 端子

两个关键参数：

参数示例说明
几 P4P、3P、2P极数
多少安63A、16A、40A、10A额定电流

本项目电源部分示例（第一页）：

器件参数
1 个4P 63A
2 个3P 16A、3P 40A
3 个2P 10A（共 3 个两 P 空开）

读图 + 布局示例：

  • 原理图：4P 63A 空开 → 布局图：全柜 唯一 一个 4P 63A → 对应 该物理位置。
  • 原理图：3P 16A 空开 → 上方端子接线缆 105、106、107；下方端子接 100、101、102。

讲师口误纠正：105/106/107 与 100/101/102 对应的是 3P 16A 空开，不是 4P 空开。

整流桥模块

  • 图例 + 原理图上 写中文名称 的器件，直接按名称识别。
  • 本项目为 公司自主研发 整流桥模块。
  • 布局图 确定安装位置。
  • 模块上有 编号端子（如 1、2、3、4、5、18、19、20…）；原理图 只接有引出线号 的端子，未引出线号的端子不用配线、不用关心。

示例（原理图需接线端子）：

  • 3 和 2、1 和 18、4 和 5、19 和 20、10 和 11、12 和 13 等（以实际图纸为准）。

接触器 KM

项目说明
KMKontaktMotor → 接触器
KM1 常开触点符号上下端子 + 一根线往外拨 → 常开触点
KM1 常闭触点符号上下端子 用线相交连在一起 → 常闭触点
KM1 线圈符号方框 / 线圈图例 → 接触器的 线圈

线圈与触点的关系：

  • 同一 KM1 的线圈、常开、常闭 都在同一个物理接触器上。
  • 实物接触器端子有编号（如 A1、A2 线圈；1L1、3L2、5L3 主触点；13NO、14NO 辅助触点等）。
  • 原理图中 KM1 线圈 与 KM1 触点 的 KM1 是同一台接触器。

布局编号规则（接触器 / 继电器通用）：

  • 从布局图 上数第一行，从左数第一个 → KM1（或 KA1）。
  • 同行从左到右：KM1、KM2、KM3…
  • 本项目：KM1、KM2 两个接触器位置。

接线示例：

  • 原理图 KM1 下方接 100、101、102 等线号 → 到布局图 KM1 位置 的 1、3、5 等端子引出线。

交流互感器

  • 图例：交流互感器。
  • 读图：穿入 某根带线号的导线（如 130）。
  • 130 同时接到 KM1 的 6 号端子 和 KM2 的 2 号端子 → 130 这根线 穿过互感器 后接到其他图纸/器件。

器件参数示例布局
变压器200W 24V（也可写 200VA 24V）布局图有对应位置
24V 开关电源—布局图有对应位置

接线线号（以项目图纸为准）：

器件线号
变压器114/116、115/117
开关电源104/103/118/119；上接 14/16，下接 15/17；一侧 140/131/041/03，另一侧 118/119

继电器 KA（单个继电器）

项目说明
KA继电器（单个）
KA1第 1 只继电器；项目若装 10 只 → KA1～KA10
常开触点端子间 一根线往外拨（如 6-10 一对、7-11 一对）
常闭触点端子 线相交连在一起

布局规格：

规格含义
四开四闭4 组「开+闭」触点组合（不是 4 个常开 + 4 个常闭简单相加）
两开两闭2 组「开+闭」组合

关键概念： 「开和闭是一组」。用 2 个常开 = 占掉 2 组里的 2 个「开」，等价于 用掉了 2 个常闭配额；用 1 个常闭 = 占 1 组里的「闭」，等价于 用掉 1 个常开配额。

KA1 实例分析：

  • 原理图上一页：KA1 两个常开（6-10、7-11）。
  • 下一页：KA1 一个常闭（14-12）。
  • 合计用了 3 组开闭 → 需要 四开四闭 继电器，不能 装两开两闭。

KA1～KA4 布局：

  • 四开四闭区共 4 个位置：第一行从左 → KA1、KA2、KA3、KA4。
  • 原理图用到 KA1～KA4 → 均放在 四开四闭 区域。

KA5 实例：

  • 仅 1 个常闭触点 → 放在 两开两闭 区域。

继电器 vs 接触器

对比继电器 KA接触器 KM
功能一样 — 都是「开关」一样
区别控制 小信号 / 小电流 负载控制 大电流 负载
类比小瓦数灯泡（如 ~10W）大瓦数灯泡（如 ~100W）
本项目上风口、下风口等 控制回路保温泵 等大电流负载

图纸上同时有继电器和接触器，是因为 所带负载大小不同，功能本质相同。

按钮与旋钮类器件

识别通则

  • 图例带 手形 / E 标识 → 按钮或旋钮（需手操作）。
  • 常开按钮： 上下端子 不连通（断开状态）。
  • 常闭按钮（停止按钮）： 上下端子 连通（如停止按钮图例）。

手自动切换按钮

  • 图例：手自动切换按钮（旋钮类，手旋转切换）。
  • 原理图文字「手动 / 自动」→ 即此按钮。
  • 全图仅 1 个 → 面板布局图 唯一位置。

停止按钮

  • 原理图共 3 个 停止按钮 → 面板上有 3 个 红色停止钮（保温泵停、风口一停、风口二停 / 上风口停、下风口停）。

开 / 关按钮（成对规则）

  • 图例：开或关按钮（同一符号）。
  • 成对出现 时：左边 = 开按钮，右边 = 关按钮。

保温泵示例（KM1 大电流负载）：

线号/位号面板含义推理链
4S2保温泵停停止按钮 → 控制 KM1 线圈 → KM1 主触点下接 保温泵
4S3保温泵开成对左侧 → 开按钮 → KM1
4S5保温泵关成对右侧 → 关按钮 → KM1

关联方法（重点）：

  1. 停止/开/关按钮 → 看接入 哪只继电器/接触器的线圈（如 KM1、KA1）。
  2. 该线圈与 同名触点 属 同一物理器件。
  3. 接触器 主触点下方 接什么负载（保温泵、风口…）→ 按钮 控制的就是该负载。

风口按钮与 KA1～KA4

继电器控制对象
KA1、KA2上风口（风口一）
KA3、KA4下风口（风口二）
  • KA1 线圈上的停止按钮 → 上风口停 / 风口一停。
  • KA3/KA4 线圈上的停止按钮 → 下风口停 / 风口二停。
  • 成对开/关同理 → 上风口开/关、下风口开/关。

指示灯（按钮自带灯）

图例含义
H1、H2…绿色 / 黄色按钮 自带指示灯

规则： 与 同一回路 中的开/关按钮 成对 → 该灯的线接在对应按钮端子上。

示例：

  • 4H1 → 保温泵开 按钮上的灯 → 接开按钮 X1、X 端子，线号 101、141、103 等（以图纸为准）。
  • 4H2 → 保温泵关（黄按钮）上的灯 → X、Y 端子接 4H2。

模组 = 把多个继电器 合并到一块板 上。

名称说明

小型控制器同上

复杂回路怎么读（最密的那一页）

  1. 先认符号 — 查图例（手自动、停止、开/关、线圈、触点、模组、H 灯）。
  2. 再追回路 — 从按钮 → 线圈 → 同名触点 → 最终负载。
  3. 数数量 — 原理图几个停止钮 = 面板几个停止钮。
  4. 成对分左右 — 开/关按钮左右定序。
  5. 不要一次全懂物理原理 — 常开/常闭 先会认符号；线圈 先理解=实现开关停功能的部件 即可。
