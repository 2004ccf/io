PID 控制论文笔记：Give us PID controllers and we can control the world

IFAC 2024 论文解读：PID 为何仍是工业控制主角、与 MPC 的分层关系，以及生活中的 PID 应用与软硬件实现。

Jun 30, 2026

读这篇论文的背景

学自动化、接触博图和 FMTP 设备之后，我一直听到 PID，但印象里它「很老、很基础」。直到看到 IFAC 2024 这篇短文 Give us PID controllers and we can control the world，以及公众号《PID控制世界？》的转发，我才意识到：工业界并没有因为 MPC、智能控制这些新名词而抛弃 PID，相反，超过九成的控制回路仍在用它。

作者是瑞典隆德大学的 Tore Häglund 和西班牙阿尔梅里亚大学的 José Luis Guzmán。我把读后的笔记按「论文在说什么」「我自己怎么理解 PID」「软硬件实现」三块写下，方便复习，也便于向老师说明我读了什么、学到了什么。

论文基本信息与核心立场

  • 题目：Give us PID controllers and we can control the world
  • 出处：IFAC PapersOnLine 58-7 (2024) 103–108

作者想证明的大意是：

  • PID 是自动控制领域最重要、影响最深的发明之一，对工业和社会的贡献，可以和电、蒸汽机等经典发明放在同一量级来谈。
  • 在 MPC、鲁棒控制、自适应控制、智能控制等算法大量出现之后，PI/PID 仍是工业界绝对主角，覆盖超过 90% 的工业控制回路。
  • PID 不应被简单当成「过时技术」，而是自动控制领域的形象大使和基础构件；在可预见的未来，绝大多数单回路问题里它仍是默认首选。
  • PID 与 MPC 等高级算法是互补、分层关系，不是谁取代谁。

历史：从自动舵到「看不见的基础设施」

1922 年，Minorsky 为美国海军设计自动舵时提出 PID 控制原型。之后几十年，PID 在化工、冶金、造纸等过程工业成为主流，再扩展到：

  • 能源：发电、输电、配电
  • 制造与过程控制
  • 日常设备：汽车巡航、空调、烤箱、微波炉、无人机、电动自行车、电梯、平衡车等

如今 >90% 工业控制回路基于 PI/PID；高校教反馈控制，PID 几乎是标准范例。它已经从一个公式，变成基础设施级的隐形技术——用户很少意识到背后有 PID，但每天都在用。

作者说的「韧性」（Resilience）：为什么百年还在用

论文用 Resilience 形容 PID 的生命力，我归纳成三点：

1. 适用面极广
温度、压力、流量、转速、位移、液位等单回路问题，整定得当往往够好，甚至接近更复杂算法。

2. 现代 PID 远不止 P、I、D 三项
工业控制器里常见：信号滤波、前馈、防积分饱和（anti-windup）、无扰切换（bumpless transfer）、限幅与模式切换等。今天的 PID 块更像小型控制平台，不是三个系数那么简单。

3. 结构简单，性能却不差
在带时滞的一阶、二阶等常见过程上，合理整定的 PID 闭环性能可非常接近更复杂的最优控制；算上实现成本、维护难度和鲁棒性，性价比往往最高。

PID 和 MPC：分层配合，不是对立

工程里常见结构是分层控制：

  • 上层：MPC 或其他优化控制——多变量协调、约束处理、经济优化，输出最优设定值或轨迹。
  • 下层：PI/PID 回路——快速反馈、局部稳定、抗扰。

论文强调：高层用 MPC 做优化时，底层回路绝大多数仍是 PID——够快、够稳、实现简单、工程师普遍会调。PID 是分层架构里的基层执行核心；MPC 更适合在上层做优化与协调。

单回路场景下，稳定过程、带时滞过程、积分或弱不稳定过程等，都有成熟的 PID 设计与整定方法（IMC、Ziegler–Nichols 改进、频域设计等）。加上前馈、滤波、anti-windup 和限幅，多数现场对性能 + 安全 + 成本的要求都能满足。在「单回路 + 能落地 + 好维护」的约束下，作者认为 PID 现在和可预见的未来仍是最佳默认选择。

作者对未来的呼吁（我摘录的要点）

  • 承认 PID 的历史地位和现实价值：少数被持续研究超过一百年的控制技术之一，不宜简单贴「落伍」标签。
  • 在 PID 上继续研究有意义：更易用的整定方法与工程工具；分层、模块化架构里 PID 与 MPC 的协同；教学上强调 PID 是一整套工程实践，不只是一个公式。
  • 学界应重视工程现实：PID 在工业中占统治地位，在 PID 上每前进一步，社会价值往往大于在冷门新算法上迈一大步。

自动控制常被称为「隐藏技术」——广泛存在于能源、交通、制造和日常生活。反馈是自动控制的心脏，PID 是反馈在工业界最成功、最现实的实现之一。论文标题那句「给我们 PID，我们就能控制世界」，是在强调这种基础性，而不是说 PID 万能。

PID 是什么：我用自己的话解释

一句话：PID 是自动纠错系统——不停看「目标值」和「实际值」差多少，自动调节，让实际值尽快跟上目标。

用开车理解 P、I、D

假设我在高速上想保持 120 km/h：

  • P（比例）：现在只有 100，差 20，就多踩油门；差越大，踩得越狠。
  • I（积分）：若老停在 118 附近，误差一直积着，会持续加力直到真到 120。
  • D（微分）：若速度蹿得太快（100 突然到 130），提前松油，避免 overshoot。

三个合在一起，就是自动把速度稳在 120。

生活里我能想到的十个例子

  1. 空调：设 26℃，检测室温，制冷或制热，微调至稳定。
  2. 电热水壶：设 100℃，快到点时减功率，避免烧过头。
  3. 汽车巡航：设 80 km/h，上坡多给油、下坡少给油。
  4. 平衡车 / 电动滑板车：检测重心角度，调电机转速。
  5. 无人机悬停：检测高度，调螺旋桨转速。
  6. 电梯平层：快到楼层减速，精确停位，不冲过头。
  7. 烤箱 / 微波炉：设 180℃ 烤蛋糕，开关加热元件保恒温。
  8. 洗衣机甩干：设 800 转/分，调电压或频率恒转速。
  9. 恒温花洒：设 38℃，调冷热水比例。
  10. 手机快充：检测电压电流，调节功率，防过充。

凡是「要把某个物理量稳在目标上」的场景——温度、速度、位置、压力、液位、流量——PID 出现概率都很高。它像一种通用稳定器：不一定最优，但简单、可靠、工程师熟。

我学完后还在想：P、I、D 调不好会怎样？比如空调温度一直波动、平衡车容易摔——这和我以后在 FMTP 里调伺服、温控、压力回路是直接相关的。

PID 都在软件里吗？三种实现方式

不全是。 现代大多数是软件，但历史上和特殊场景也有硬件或混合。

1. 软件实现（我现在接触最多）

算法写在程序里，跑在 CPU 或微控制器上。

  • PLC / 博图：调用 PID_Compact 等功能块，就是软件 PID，跑在 PLC CPU 上，HMI 可改 P、I、D。
  • 单片机 / 嵌入式：平衡车、无人机里的控制代码。
  • 工控机、DCS：模块本质也是软件。

优点：灵活、便宜、能加滤波、anti-windup、前馈；升级调试方便。空调 MCU、汽车 ECU 巡航同理。

2. 硬件实现（现在较少）

用模拟电路（运放、电阻、电容）直接做 P、I、D，不需要 CPU。P 用运放放大，I 用电容积分，D 用电感/电容微分。老式温度控制器旋钮调参，背后常是模拟电路；激光功率等微秒级场景仍有需求。

优点：响应极快、不受扫描周期影响；没有软件 bug 一类的问题。缺点：改参数要动电阻电容，很麻烦；很难加滤波、anti-windup 等复杂功能。

例子：1970–1990 年代老式工业温控器；激光器功率控制等需要微秒级响应的场合。

3. 软硬件混合

核心计算放在 FPGA、DSP 等专用硬件上，参数整定和逻辑切换仍用软件完成。高速运动控制、航空航天、医疗设备、多轴同步等场景常见。

例子：伺服驱动器里 DSP 算 PID、上位机或面板改参数；高精度机器人控制器用 FPGA 做运算、软件侧调参。

为什么现在多数是软件？

我归纳论文和课堂上的说法，大致五点：

  1. 单片机成本低，几块钱就能跑 PID。
  2. 改参数、加功能、远程调试都方便。
  3. 能集成滤波、anti-windup、前馈、自适应等，现代工业 PID 块往往自带这些。
  4. 升级、备份、和 HMI 联动维护成本低。
  5. 对多数工业过程，PLC 扫描周期已经够快，软件 PID 能满足需求。

硬件实现仍出现在：响应要微秒级、系统不容许软件延迟、或极简单低成本模拟控温等场合。

实现方式常见场景优点缺点现代占比（行业说法）
软件PLC、单片机、DCS灵活、成本低、功能强受 CPU 性能限制绝大多数
硬件老式模拟、极快响应极快、实时性好不灵活、成本高很少
混合伺服、多轴运动快且可调成本较高少量

和我专业的联系

在博图里：PID_Compact 是典型的软件实现，运行在 PLC CPU 上，HMI 可改 P/I/D 参数。

在 FMTP 设备里：伺服位置可能在 PLC（软件）或驱动器（偏混合）；温压控制多在 PLC 或温控器（偏软件）。

论文里几个主题，我用自己的话再捋一遍

引言与「隐藏技术」
自动控制渗透在经济、生命、能源、交通、制造里，用户往往意识不到。反馈是核心，PID 是工业界最成功、最现实的反馈实现之一。

历史与应用版图
从 1922 自动舵到过程工业，再到家电和出行设备；今天 >90% 回路用 PI/PID，高校教学也绕不开它。

演化与韧性
从三个系数到带滤波、anti-windup、前馈、无扰切换的「小平台」；和级联、多变量、分层、自适应结构结合，常作为底层执行模块；在典型过程上性能可接近更复杂最优控制。

与 MPC 等的分工
不是替代关系；上层优化、下层 PID 快反馈，高级算法与 PID 协同。从可实施性、维护成本、人员技能看，PID 长期是底层基石。

未来研究方向（作者呼吁）
更好的整定工具；模块化/分层里 PID 的接口设计；工业 4.0、智能制造下与数据驱动、AI、MPC 的融合——教学上别把 PID 教成三个字母而已。
