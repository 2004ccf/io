沙盘记账后台（只有你能进）

这是干什么的？
这里用来改玩伴名单、投资金额、分红和公告。改完后导出一个数据文件，覆盖上传，大家看的展示页就会更新。
注意：这个网址不要发给外人；展示页上也没有后台入口。
作用：防止别人乱改账本。默认密码是 sandbox2026，用完请尽快改掉。

你只需要记住 3 步：
① 在下面改数据（加人、改投资、发公告、算分红） → ② 点最上面的「保存成数据文件」 → ③ 把下载的 sandbox.json 覆盖上传到网站的 data 文件夹
约束：人数≤15人；单人出资与整体总额不设金额上限。网站不收钱，转账都在线下做。
纠错模式：正在检查…

    总览当前账本状态

    这里只看一眼「现在账本里有多少人、多少钱」，不用改。真正改数在下面各模块。纠错模式会拦住不合理的数字。
    上次更新：— 玩伴人数：— 总娱乐本金：— 已投入本金：— 还可投入：— 当前总资产：— 累计盈亏：— 沙盘净值（自动）：—

    全自动联动：改玩伴/投资/分红/勾选已转账 → 统一重算入金、饼图、每人已分红、现金、总资产、净值。 现金 = 总本金 − 持有中投入 + 已了结盈亏 − 已转账分红（勾选「已转账」才出池；仅结算未转账不扣）。总娱乐本金只随玩伴名单变。

    保存 / 导出（改完必做）

    保存成数据文件 —— 作用：把你刚改的内容打包成 sandbox.json 下载下来。 你要把这个文件上传覆盖网站上的旧文件，大家打开展示页才能看到新数。
    导出 Excel 表格 —— 作用：下载一份可用 Excel 打开的账目表，方便打印或微信发给玩伴对账。不影响网站显示。
    本机先预览 —— 作用：不上传服务器，先在你自己电脑上看看效果。打开展示页时地址后面加 ?preview=1。
    从文件恢复 —— 作用：如果你电脑里有以前备份的 sandbox.json，可以重新加载进来接着改。
    退出后台 —— 作用：关掉管理权限，别人用这台电脑时进不来改账。

    3投资台账（钱投到哪里了）

    作用：用三步把「投出去的钱」记清楚；下面表格跟进每笔赚亏。展示页右侧台账和总资产都看这里。
    纠错规则：所有「持有中」投入合计不能超过总娱乐本金；市值不能为负。市值请按账单/结算手填，不自动拉网价。
    自动核算：改市值或「标记已了结」后，总资产 / 累计盈亏 / 净值立刻重算；了结时的赚亏会加回现金（已实现），不会从账本消失。总娱乐本金只随玩伴名单变，不会因了结而变。

    5流水（自动生成，不用手填）

    不用再手动添加流水。系统会自动记账：
    · 入金：每次保存/改数都会按玩伴当前本金自动重算（与总娱乐本金对齐）
    · 追加/退伙：改本金或删人时自动记差额流水
    · 分红：结算写入；勾选「已转账」后才从池子扣资产
    下面表格与展示页同步。也可手动点「一键重算入金」。
    作用：与自动联动相同——按每人当前娱乐本金重写入金表。分红流水不会被清掉。
    入金合计：¥0.00 作用：所有入金金额相加，应接近「总娱乐本金」。
    分红合计：¥0.00 作用：历次自动分红流水金额相加。

    改完之后做什么？

    1. 回到本页最上面，点 「① 保存成数据文件」
    2. 得到 sandbox.json，上传覆盖网站目录里的 data/sandbox.json
    3. 打开展示页刷新一下（或等约 30 秒自动刷新）
    4. 分红/出资记得线下转账，备注写「娱乐沙盘出资/分红」
